# AIM-PHI Results Visualization

This repository contains R scripts for visualizing the results of an AIM-PHI.

## Directory Structure

- `data/`: Input data for visualization (excluded from Git).
- `output/`: Figures.
- `prog/`: R scripts for generating figures.

## Requirements

- R
- Required R packages (specified in the scripts)

## Usage

1. Prepare the required input data in the `data/` directory.
2. Set the working directory to the repository root.
3. Run the R scripts in the `prog/` directory.
4. Generated figures are saved in the `output/` directory.

## Notes

Input data and generated figures are excluded from version control using .gitignore.
